FAQ

Questions developers ask first

Is it free?

Yes. OpenPurpose is open source under the MIT licence, so self-hosting costs nothing but your server. You can also start on the hosted version for free.

Can I self-host it?

Yes. It ships as one Docker image, ghcr.io/openstuff-dev/open-purpose, configured with environment variables. Clone the repository and run docker compose up -d.

Which agents work with it?

Any agent that speaks MCP: Claude Code, Cursor, Codex, VS Code and others. The agent calls get_context before a task and propose_learning when you correct it.

Where is my data?

On the hosted version, in our database, with every workspace separated by Postgres row-level security. When you self-host, on your own servers. Either way you can export everything as JSON or Markdown.

How is this different from a CLAUDE.md file?

A CLAUDE.md is one file in one repo, read in full by one kind of agent. OpenPurpose keeps each rule once, serves only the rules for the code an agent is in, works with every MCP agent, and turns your corrections into reviewed rules with history.

You still keep a short AGENTS.md or CLAUDE.md: it tells the agent to call OpenPurpose.

Does it send my code anywhere?

No. To get context, the agent sends three things: the git remote, the file path and the manifest (package.json, *.csproj). Your source code stays where it is.
